# Sattva Homes website

This is the Sattva Homes website (Next.js 16). The `CLAUDE.md` one level up on the Desktop belongs to a different project (Gate Check-in Scanner) and does not apply here. Don't touch the separate `Desktop\satvahomes` folder either; it's unrelated.

- Read `README.md` for structure and commands.
- Brand: navy `#19283F`, gold `#AC8654` (from the logo). Fonts: Newsreader for headings (`.display`) and italic accents (`.serif`), Archivo for body text. Tokens and shared classes (`.btn`, `.section`, `.section-head`, `.eyebrow`) live in `src/app/globals.css`.
- Brand promise (from the marketing brief): "Clarity before commitment, and a home delivered as agreed." Voice: educational, a knowledgeable guide, professional but approachable. No sales gimmicks, no generic builder hype.
- The client doesn't want flashy animation. The homepage is static and leads with clarity: who Sattva is and what it promises, then designs, process, lifestyle, track record and the display home. The only scroll animation is the 3D build on `/how-we-build`; animated components there must check `useMotion().enabled` and use `useGSAP` with `revertOnUpdate: true`, so the static version stays complete.
- The site is light: ivory and white sections, navy text, gold accents (`--gold-ink` for gold text on light). Navy is kept to the display home panel, the footer and the build scene at night. Navy surfaces must set their own light text colour, because the page default is navy.
- Styling is CSS Modules plus global tokens. No Tailwind.
- `src/data/designs.json` is generated by `npm run import:designs`. Don't edit it by hand.
- SEO: target terms are "home builder Brisbane", "house designs Brisbane" and "display home Willawong". Every page needs a unique title (≤60 characters including " · Sattva Homes"), a meta description (≤160), one H1, and a canonical URL. Business details for search engines live in `businessJsonLd` in `src/lib/site.ts`. Use the terms naturally; don't keyword-stuff.
- All copy is draft until the client signs off. Don't invent claims such as awards, years in business, reviews or guarantees.
- Before finishing a change, run `npm run typecheck`, `npm run lint` and `npm run build`.
